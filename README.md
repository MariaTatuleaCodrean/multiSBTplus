# multiSBTplus
Slender Body Theory PLUS Hydrodynamic Interactions: MULTIPLE filaments edition

MATLAB code adapted from the article 'Physical mechanism reveals bacterial slowdown above a critical number of flagella' by M. Tătulea-Codrean & E. Lauga. (2024) _J R Soc Interface_, **21**: 20240283.

Currently available demos:
* **demo**: calculate the axial forces and torques on four parallel helical filaments rotating with constant velocity
